Bản thiết kế Tổng thể: Universal Task Runner

Hệ thống điều phối tác vụ tập trung cho VVR-Scraper.

1. Entry Point

Lệnh vvrt run job.json sẽ parse JSON và chuyển hướng luồng xử lý tới các module tương ứng.

2. Unified Server

Khởi chạy FastAPI phục vụ cả WebUI và OPDS. Đồng thời kích hoạt Background Worker.

3. Smart Queue

Worker lấy Job từ hàng đợi, thực thi tuần tự (FIFO) để bảo vệ tài nguyên hệ thống.

Cơ chế Báo cáo lỗi (Error Reporting):

error-logs/job_xyz.log
--- JOB MANIFEST ---
{ "task": "server", "automation": { "schedules": [...] } }

--- STACK TRACE ---
Exception: Database is locked...

Ưu điểm cuối cùng

  • Chuẩn hóa mọi thao tác vào file JSON.
  • Quản lý lịch sử tác vụ như một ứng dụng Enterprise.
  • Khả năng tự động hóa không giới hạn.
