Thiết kế: Universal Task Runner (`vvrt run`)

Một file JSON duy nhất để điều khiển mọi khía cạnh của hệ thống.

Universal Manifest Structure
{
  "task": "video-render", // Loại nhiệm vụ chính
  "target": {
    "slug": "linh-vu-thien-ha",
    "range": "100-110"
  },
  "params": {
    "fps": 60,
    "quality": "high",
    "auto_upload": true
  }
}

Các loại Task chính sẽ hỗ trợ:

📦 Crawl / Export

Quét truyện và xuất ra các định dạng (EPUB, PDF, MP4, MP3).

🌐 Web Services

Khởi chạy WebUI hoặc OPDS Server với cấu hình định sẵn.

🎬 Automation

Kịch bản tự động hóa (Ví dụ: Watch & Scrape truyện mới).

Tại sao kiến trúc này lại "Pro"?

  • Single Entry Point: Bạn chỉ cần bảo trì 1 lệnh duy nhất.
  • Easy Debugging: Chỉ cần gửi file JSON là tôi có thể tái hiện chính xác lỗi của bạn.
  • Cloud Ready: Rất dễ để đóng gói vào Docker và chạy trên Server.
