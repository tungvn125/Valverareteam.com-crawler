Kiến trúc: Unified Server & Autonomous Scheduler

Kết hợp cấu hình khởi động và kịch bản vận hành tự động trong 1 file JSON.

Unified Job JSON (The Brain)
{
  "task": "server",
  "config": {
    "host": "0.0.0.0",
    "port": 8000
  },
  "automation": {
    "schedules": [
      { "action": "library_rescan", "every": "6h" },
      { "action": "scrape_hot_novels", "at": "00:00" }
    ]
  }
}

Luồng điều phối (Orchestration):

1. Startup Phase

vvrt run đọc JSON, khởi tạo FastAPI & OPDS Server trên cổng được chỉ định.

2. Runtime Phase

Một Background Worker (như APScheduler) sẽ "thức dậy" định kỳ dựa trên kịch bản trong JSON để thực hiện nhiệm vụ.

Lựa chọn xử lý xung đột Task:

A

Task Queuing (An toàn)

Xếp hàng các nhiệm vụ tự động. Đảm bảo an toàn cho Database và không gây quá tải CPU.

B

Parallel Execution (Hiệu năng)

Chạy song song mọi nhiệm vụ. Tận dụng tối đa đa nhân CPU nhưng cần cơ chế Lock DB phức tạp.
