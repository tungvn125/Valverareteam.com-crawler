Bản thiết kế Section 1: Universal Manifest Structure

Định nghĩa ngôn ngữ chung cho mọi tác vụ trong hệ thống.

Ví dụ: server_with_automation.json
{
  "version": "1.1",
  "task": "server",
  "payload": {
    "host": "0.0.0.0",
    "port": 8000,
    "opds_password": "admin123"
  },
  "automation": {
    "enabled": true,
    "schedules": [
      {
        "id": "daily-sync",
        "action": "scrape-updates",
        "cron": "0 2 * * *",
        "params": { "format": ["MP3"] }
      }
    ]
  }
}

Quy tắc hàng đợi (Queuing Rules):

  • Tối đa 1 Worker: Tại một thời điểm chỉ có 1 tác vụ nặng (scrape/render) được thực thi.
  • Ưu tiên: Các tác vụ CLI trực tiếp (nếu có) sẽ được đẩy lên đầu hàng đợi, các tác vụ lập lịch chạy sau.
  • Trạng thái: Server cung cấp một API /api/jobs/status để theo dõi hàng đợi hiện tại.
