Ý tưởng: Declarative Job Runner (`vvrt run`)

Chuyển từ "Cầm tay chỉ việc" sang "Giao phó bản thiết kế".

Cách cũ (Imperative)

// Phải nhớ lệnh hoặc bấm menu

$ vvrt slug -f MP4 --fps 60 --format portrait -g tatca

⚠️ Dễ gõ sai, khó lưu lại cấu hình, khó tự động hóa hàng loạt.

Cách mới (Declarative)

// Chỉ cần 1 lệnh duy nhất

$ vvrt run my_movie_job.json 
{
  "novel": "slug",
  "format": "MP4",
  "fps": 60,
  ...
}

✅ Chuyên nghiệp, dễ chia sẻ, lặp lại 100% kết quả.

Bạn chọn quy mô nào cho Job?

A

Single Novel Job

Tập trung cấu hình cực chi tiết cho 1 bộ truyện (custom voice cho từng nhân vật, vfx riêng biệt).

B

Batch Processing Job

Một file cấu hình xử lý hàng chục bộ truyện cùng lúc (ví dụ: quét toàn bộ genre "Tiên hiệp" và xuất ra MP3).

Lợi ích kỹ thuật

  • Validation: Dùng Pydantic để check lỗi cú pháp JSON cực nhanh.
  • Version Control: Có thể commit các file .json này lên Git để quản lý lịch sử render.
  • Scale: Dễ dàng chạy trên Server/Docker mà không cần UI.
